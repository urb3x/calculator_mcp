🛠️ Available Math Tools

Tool Parameters Description
calculate expression: str Evaluates expressions (e.g. sqrt(16) + 2^3, sin(pi/2))
add a, b Adds two numbers
subtract a, b Subtracts b from a
multiply a, b Multiplies two numbers
divide a, b Divides a by b (protects against zero division)
sqrt n Square root calculation
